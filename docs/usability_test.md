# Usability test script (Phase 10)

Status: script ready, **results not yet collected**. Nothing below is a finding.

## Setup

- 5 participants who run or market a small business; none has used GrowthCrew.
- Demo workspace with sample data (`uv run python -m evals.demo_seed`), on a phone and a laptop.
- One facilitator, one note-taker. Sessions of about 30 minutes, recorded with consent.

## Tasks

1. Find out what GrowthCrew is doing this week (mission page). Success: names the current stage.
2. Approve one draft and reject another using only the keyboard (laptop) or one thumb (phone).
3. Edit a draft, then find what you changed (tracked changes).
4. Find out whether last week's test had a winner, and how sure we are.
5. Connect Slack in Settings and explain what happens when you press Approve in Slack.
6. Replay last week from start to finish.

## What to record per task

Completed (yes, with help, no), time taken, errors, and the participant's own words.
Afterwards: the five-question SUS short form and "what would stop you using this weekly?".
